======================================================================
0. 本计划的唯一目标
======================================================================

目标：
    在当前固定的三维运动学仿真合同下，验证 4 架追捕无人机在部分可观测、
    中央混合静态障碍和持续逃逸目标条件下，能否稳定完成“捕获半径内捕获 +
    安全执行 + 至少 2/4 架进入障碍区”的协同围捕。

最终要回答的问题：
    1. 当前 V4 Retained-BC + CBF 正式基线能否被 V5 随机障碍/观测扰动复现？
    2. 若不能，失败来自训练数据分布、观测扰动、长期协同决策还是 CBF 执行层？
    3. 一个只改变单一主因素的候选，能否在未见 locked-test 上稳定改善，而不是只
       在一个验证 seed 或一个视频中成功？

研究边界：
    - 4 架追捕机、1 架目标机，捕获半径 r_capture = 0.80 m。
    - 三维运动学环境；障碍物为圆柱、立方体、墙体，位于中央区域。
    - 部分可观测由检测范围、噪声、延迟和丢失等合成扰动表示。
    - CBF 是执行栈的一部分；raw actor 与 policy + CBF 必须分开报告。
    - Capture 是几何捕获半径事件，不代表实体接触、网捕、物理拦截失能、SITL
      或实飞成功。

本计划不做：
    - 不改变 0.80 m 捕获半径、碰撞规则、边界规则或 2/4 协同定义来提高成功率。
    - 不把目标穿越中央障碍区设为捕获前提；目标只需被捕获。
    - 在 V5 主结论完成前不同时加入动态障碍、多目标、未知地图、真实视觉和六
      自由度动力学。

2. 固定协议、指标和通过线
======================================================================

协议文件：
    configs/central_random_mixed_obstacle_s3_v5_protocol.yaml
    configs/capture_radius_recurrent_behavior_cloning_central_v5_baseline.yaml

冻结 seed：

    V5 next locked-test：647201（模型和参数全部冻结后才可运行）
    V4 locked-test：647001（禁止用于调参）

指标定义：
    Capture：任一追捕机首次进入目标 0.80 m 捕获半径。
    Safe Capture：首次 Capture 前无障碍碰撞、机间碰撞和越界。
    Cooperative Safe Capture：Safe Capture 且捕获前至少 2/4 架追捕机进入中央
        障碍区；目标无需进入中央区。
    Transit：独立的地图通行性指标，不是 Capture 的附加条件。

候选最低通过线（V5 validation）：
    - Cooperative Safe Capture >= 85%。
    - Collision <= 2%。
    - Boundary violation <= 2%。
    - Transit >= 99%。
    - 固定 S1 cylinder/box/wall 和 S2 mixed + CBF 均 >= 98%。
    - delayed_noisy、窄净空等困难分组必须有可解释改善，不能只提升容易组。
    - 不得靠延长 episode 时间、明显降低最小净空或异常放大 CBF correction 换取
      成功率。

正式完成线（V5 next locked-test）：
    - 最佳方法的 3 个独立训练 seed 全部完成固定回归和 validation。
    - 3 个 checkpoint 均在独立 647201 locked block 上评估，每个 100 episode。
    - 只有 3 seed 均符合安全门槛且总体达标，才能写“在当前仿真合同下稳定改进”。
    - 若未达标，保留 V4 为正式最佳基线，V5 只写“开发候选未稳健复现”。

5. P2：单因素改进实验（按顺序，禁止并行堆方法）
======================================================================

共同规则：
    - 每轮只改变一个主因素；先用 1 个 pilot seed，过门槛后才扩展到 3 seed。
    - 保持捕获半径、2/4 协同定义、网络主体结构、动作尺度、episode horizon、
      optimizer 和 CBF 默认参数不变。
    - validation 646101 可用于选择；647201 仍然完全不可见。
    - 每个候选保存 YAML、git hash、训练 seed、数据 archive hash、拒绝原因和日志。

P2-0：固定场景契约恢复（当前默认第一步）
    触发：V5 baseline 固定 S1/S2 + CBF 低于 98%，或出现大量碰撞。
    [ ] 从 V4 已验证专家流程重新生成固定 S1/S2 覆盖演示，并保留 V5 随机场景
        演示；不是简单增加总 episode 数。
    [ ] 训练数据至少包含 cylinder、box、wall、S2 mixed、左右出生侧、两种目标
        motion，并保持 2/4 zone-entry 标签一致。
    [ ] 以相同总训练量比较 `V5-only` 与 `V4-fixed + V5-random` 两个版本；只改
        数据来源配比，网络和优化器不变。
    [ ] 先恢复固定回归，再检查随机 S3；固定回归未恢复不得进入难例训练。

P2-A：难例重采样/质量门控 BC
    触发：失败集中在 narrow、5 obstacles、delayed_noisy、timeout 或大 CBF 修正。
    [ ] 用 rule expert + CBF 生成难例演示；expert 无法安全捕获的地图记录为不可行，
        不放入训练集。
    [ ] 在常规演示固定不变的前提下比较 normal:hard = 1:1 与 1:2；总 episode、
        优化步数和 checkpoint 选择规则相同。
    [ ] 报告每个条件的采样量、接受率、左右出生侧和拒绝原因，防止过采样某一侧。
    [ ] 只有同时改善 hard group 且固定 S1/S2 不退化的候选才能保留。

P2-B：观测鲁棒性增强
    触发：失败主要集中在 delayed_noisy，且契约恢复/难例重采样仍不能解决。
    [ ] 一次只加入一种增强，顺序为 delay -> noise -> dropout。
    [ ] 比较 nominal-only、delayed_noisy-only、mixed 三种训练分布，总训练量一致。
    [ ] 分别报告 nominal 与 delayed_noisy，不能以 nominal 提升掩盖困难条件退化。

P2-C：轻量协同辅助项
    触发：失败轨迹显示单机追击、队形塌缩或长期无法达到 2/4 zone-entry，且不是
        窄通道或 CBF 强修正造成。
    [ ] 先生成 zone-entry 顺序、agent-agent distance、目标距离、最终接近方向和
        CBF correction 时间序列诊断图。
    [ ] 只增加一个可解释辅助损失；做无/有辅助项消融，不改 capture 定义。
    [ ] Capture、最小净空或固定回归下降则拒绝该项。

P2-D：CBF 参数敏感性（只做执行诊断，不当作学习改进）
    [ ] 在冻结 checkpoint 上比较 raw、CBF-default 和少量预注册 safety margin。
    [ ] 报告 Collision、Boundary、Timeout、Transit、最小净空、Time-to-Capture、
        path length 和 correction 的权衡。
    [ ] 选定参数后冻结，不能用 locked-test 结果反调 CBF。

明确暂缓：
    [ ] MAPPO 只有在 P2-0/A/B 都失败且逐回合证据明确显示长期协同决策不足时才启动；
        必须从合格 BC 初始化并加入行为保持正则。
    [ ] PyBullet、真实检测器、动态障碍、多目标和未知地图不进入 V5 主线调参。
