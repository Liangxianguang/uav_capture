部分可观测三维混合障碍环境下多无人机协同穿越与捕获
SHOWCASE_MIXED_OBSTACLE_CAPTURE_TODOLIST
版本：2026-08-20

======================================================================
一、全新实验目标
======================================================================

1. 核心目标

在部分可观测三维环境中，构造位于场地中央的混合障碍区，包括圆柱、
立方体和墙体障碍物。让多架追捕无人机与逃逸目标从障碍区两侧开始，
在不碰撞、不越界的前提下绕行或穿越障碍区，最终由至少一架追捕无人机
进入目标的捕获半径，完成 Safe Capture。

2. 推荐研究表述

本阶段不把“画面更好看”作为唯一目标，而是研究：

    在中央混合障碍、部分可观测、目标持续逃逸和边界约束同时存在时，
    多无人机协同策略能否安全穿越障碍区并完成捕获。

3. 最终展示效果

视频中应当清楚看到：

    [ ] 追捕无人机与目标初始位于中央障碍区两侧；
    [ ] 目标和追捕无人机从较远距离开始；
    [ ] 无人机绕过或穿过圆柱、立方体和墙体组成的障碍区；
    [ ] 所有无人机和目标始终位于场地边界内；
    [ ] 无人机之间、无人机与障碍物之间没有碰撞；
    [ ] 目标持续移动而不是静止等待捕获；
    [ ] 至少一架无人机进入真实捕获半径；
    [ ] 捕获瞬间出现高亮、冻结帧和“CAPTURE CONFIRMED”标记；
    [ ] 画面同时展示俯视地图、轨迹、捕获圈、状态指标和高度变化。

======================================================================
二、必须固定的科学定义
======================================================================

1. Capture 与 Safe Capture

Capture：

    min_i ||p_defender_i - p_target|| <= r_capture

Safe Capture：

    首次进入捕获半径前，没有发生障碍物碰撞、无人机间碰撞或边界违规。

2. 捕获圈的动态显示规则

物理判据中的真实捕获半径固定为 r_capture = 0.80 m，不能为了动画效果
随时间改变，否则会改变实验任务定义。

动画中的“动态捕获圈”采用以下安全做法：

    [ ] 真实捕获圈：固定 0.80 m，用实线显示；
    [ ] 可视化脉冲圈：只改变透明度和线宽，不改变判定半径；
    [ ] 可选不确定性圈：显示目标 belief 的位置不确定性，使用虚线；
    [ ] 捕获时真实圈变为绿色并闪烁 2-3 帧；
    [ ] 捕获后冻结最后一帧 1.5-2.0 秒并显示 CAPTURE CONFIRMED。

3. 边界定义

场地建议保持 20 m x 20 m x 10 m：

    x, y ∈ [-10, 10] m
    z ∈ [0.5, 10] m

所有初始点、目标参考路径、绕障路径和执行轨迹必须经过边界检查。
建议在边界内侧增加 1.0-1.5 m 安全缓冲，不允许策略依靠撞边反弹完成捕获。

4. 障碍物安全定义

无人机和目标都不能进入障碍物实体内部。所有障碍物周围增加安全膨胀层：

    obstacle_clearance >= drone_radius + safety_margin

建议 safety_margin 初始使用 0.35 m，并在实验中记录最小间隙。

======================================================================
三、场景设计原则
======================================================================

1. 坐标和初始位置

建议以 x 轴作为主要追捕方向：

    中央障碍区：x ∈ [-2.0, 2.0]
    追捕无人机初始区：x ∈ [-8.0, -5.0]
    逃逸目标初始区：x ∈ [5.0, 7.0]
    所有 z 坐标：0.8-6.5 m

追捕无人机和目标从障碍区两侧开始，初始最近距离建议为 9-13 m，
但必须先通过可达性检查，不能把任务设计成必然无法捕获。

2. 三类场景必须分阶段实现

S1：中央障碍区穿越拦截

    追捕无人机位于左侧，目标位于右侧；
    障碍物集中在中央；
    追捕无人机必须进入中央障碍区并绕行到目标一侧；
    目标在右侧做逃逸机动；
    用于第一段稳定展示视频。

S2：双向通过障碍区

    目标也需要穿越中央障碍区或狭窄通道；
    追捕无人机从相反方向接近；
    目标和全部追捕无人机都必须完成障碍区穿越标记；
    用于验证“所有主体均能安全过障碍区”。

S3：混合障碍泛化

    圆柱、立方体和墙体数量、方向、间距随机变化；
    中央障碍区保留至少一条可行通道；
    目标采用随机转向、S 曲线或边界逃逸行为；
    用于正式统计，不只用于视频展示。

3. 推荐的第一版固定场景

    圆柱：2 个，半径 0.8-1.1 m，高度 4-6 m；
    立方体：1 个，水平半尺寸 0.9-1.4 m，高度 3-5 m；
    墙体：1 段，长度 4-6 m，厚度 0.4-0.8 m，高度 3-5 m；
    障碍物之间至少留出一条宽度不小于 2.5-3.0 m 的安全通道；
    障碍物不得遮挡整个场地，不得制造无解地图。

四、成功判据和必须报告的指标
======================================================================

1. Showcase 单回合成功条件

    [ ] safe_capture_success = true
    [ ] capture_event = true
    [ ] collision = false
    [ ] world_violation_steps = 0
    [ ] min_clearance_m >= 0
    [ ] 目标完成指定障碍区穿越标记；
    [ ] 4 架追捕无人机均完成指定障碍区穿越标记；
    [ ] 至少一架无人机的最近距离 <= 0.80 m。

2. 正式多回合指标

    Safe Capture Rate
    Capture Rate
    Obstacle Collision Rate
    Inter-agent Collision Rate
    Boundary Violation Rate
    Defender Obstacle-zone Crossing Rate
    Target Obstacle-zone Crossing Rate
    Mean / Worst Minimum Clearance
    Mean Time-to-Capture
    Initial Separation
    Path Length and Detour Ratio
    Target Visibility Fraction
    Observation Age and Message Age
    CBF Correction Magnitude

3. 不能只报告单个最好看的视频

视频用于直观展示；论文结论必须来自至少 3 个训练 seed、固定 locked-test
seed block 和 raw/CBF 成对评估。展示视频的 seed 必须在 episode.json 中保存，
不能把视频结果当成统计结果。

======================================================================
五、是否需要重新训练的决策规则
======================================================================

阶段 0：先不重新训练

    使用现有 F2 checkpoint + CBF；
    只改变手工场景几何、起点和渲染方式；
    在 S1 场景运行 20-50 个 episode；
    如果能够安全捕获，直接作为 showcase，不修改正式 checkpoint。

阶段 1：判断是否发生分布外失败

    如果 S1 成功率较高，但 S2/S3 失败，说明当前策略可以完成基础展示，
    但尚未泛化到双向穿越或混合障碍；先记录失败边界，不要立刻堆叠网络。

阶段 2：只有满足以下条件才重新训练

    [ ] 当前 checkpoint 在 S1 固定场景也持续失败；
    [ ] 失败原因主要来自起始距离、障碍物形状或通道布局，而不是代码错误；
    [ ] 地图经过可达性检查，确实存在安全路径；
    [ ] CBF 安全层没有因为通道过窄而人为阻断所有路径。

阶段 3：课程式重训练

    T1：远距离目标 + 无障碍或单圆柱；
    T2：中央圆柱障碍区；
    T3：圆柱 + 立方体；
    T4：加入墙体和窄通道；
    T5：随机混合障碍、目标随机转向、部分观测和通信延迟；
    T6：固定 locked-test 混合障碍测试。

每个阶段只增加一个主要难度因素，保留前一阶段的场景比例，避免训练
突然退化。正式重训至少使用 3 个独立训练 seed，并保存 YAML、checkpoint、
TensorBoard、环境版本和源代码 hash。

七、推荐的实际执行顺序
======================================================================

1. 先完成 B1-B5，保证圆柱、立方体和墙体的碰撞几何正确；
2. 再完成 A1-A6，生成一个有解的 S1 固定场景；
3. 用现有 F2 + CBF 做 C1-C5，不重新训练；
4. 若 S1 稳定成功，再做 D1-D10 生成最终视频；
5. 再运行 S2/S3，判断当前 checkpoint 的泛化边界；
6. 只有确认是稳定的分布外失败，才进入 E1-E6 课程重训练；
7. 最后用 F1-F6 整理论文图、视频和统计报告。

======================================================================
八、本阶段完成标准
======================================================================

最低完成标准：

    在 S1 固定混合障碍场景中，现有 checkpoint + CBF 能够完成一条
    无碰撞、无越界、穿越中央障碍区并进入捕获半径的完整轨迹，且能输出
    可复现的 PNG、GIF、MP4 和 episode.json。

研究完成标准：

    在 S1/S2/S3 上完成多 seed locked-test，明确当前策略在中央混合障碍、
    双向穿越、远距离逃逸和复杂障碍下的成功率、失败边界和安全代价；
    如确有必要，再用课程重训练证明改进来自障碍泛化，而不是来自挑选单个
    最好看的场景。

本计划的关键原则：

    先验证现有模型能否在有解的混合障碍展示场景中工作；
    再决定是否需要训练；
    先保证几何和判据正确；
    再追求画面美观；
    先报告安全和泛化边界；
    再展示最漂亮的视频。
