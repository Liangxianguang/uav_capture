中央混合障碍穿越与协同捕获实验计划
版本：2026-08-20

======================================================================
一、最终目标
======================================================================

在固定三维边界的部分可观测环境中，4 架追捕无人机和 1 架逃逸目标分别从
中央障碍区的两侧出发。中央区域由圆柱、立方体和墙体构成，主体不得越界或
碰撞。目标沿可行通道从右侧向左侧逃逸，追捕组从左侧进入中央区实施协同
拦截；任一追捕机首次进入目标捕获半径即记为捕获成功。

本阶段的正式研究问题：

    在中央混合障碍、局部可观测、目标持续逃逸和边界约束同时存在时，
    追捕策略能否稳定完成“安全进入中央障碍区 + 协同接近 + 捕获”，并保持
    目标和每架追捕机均具备独立的安全跨区通行能力？

这是一项三维运动学仿真研究。Capture 只表示进入固定捕获半径，不表示网捕、
机械抓取、碰撞接触或实飞实体捕获成功。

======================================================================
二、任务定义：必须先固定，不能在结果出来后改变
======================================================================

1. 空间与出生约束

    [ ] 固定世界边界：x,y in [-10, 10] m，z in [0.5, 10] m；
    [ ] 中央障碍区固定为 obstacle_zone_x = [-2.5, 3.0] m；
    [ ] 追捕方出生在左侧安全出生区，目标出生在右侧安全出生区；
    [ ] 每个主体距世界边界至少 1.0 m，距障碍物至少 drone_radius + safety_margin；
    [ ] 不允许通过撞边界反弹、穿模或从地图外绕行获得成功。

2. 捕获契约与独立通行验证（本计划的关键新增点）

    [ ] Target Zone Entry：目标至少一次进入中央障碍区，且其规划路径通向左侧外部区域；
    [ ] Pursuer Zone Entry：至少一架追捕机进入中央障碍区；记录 4 架追捕机各自的进入状态；
    [ ] Capture in Pursuit：捕获发生在双方按相反方向通过中央区、实施拦截的过程中，
        或发生在目标离开中央区后的短距离追击过程中；
    [ ] Safe Capture：首次进入 r_capture = 0.80 m 前无障碍碰撞、机间碰撞和边界违规；
    [ ] Showcase Success：Safe Capture + Target Zone Entry + Pursuer Zone Entry；任何缺项都只能记为部分成功；
    [ ] Transit Success（独立通行试验）：在不启用捕获终止的受控试验中，目标由右至左、
        每架追捕机由左至右均抵达对侧外部区域，且无碰撞、无越界。

说明：捕获发生后目标应停止，因而不能要求目标和 4 架追捕机在同一捕获回合中
都先完成对侧穿越，否则会人为制造“交换位置后再折返”的非自然任务。主任务
验证中央区相遇拦截；Transit Success 是独立的通行能力与地图可行性验证，两者
分别统计，不混为一个成功率。

3. 可行性与公平性约束

    [ ] 每张地图对目标和每架追捕机分别进行保守路径可达性检查；
    [ ] 连通通道宽度必须大于主体直径加双侧安全裕度；
    [ ] 出生点、捕获点、障碍物 footprint 和边界缓冲区不得重叠；
    [ ] 目标的机动上限、最大速度和加速度不得超过追捕组整体可处理的范围；
    [ ] 先由 rule expert + CBF 在每类场景连续成功 20 回合，才允许将该类场景用于学习策略训练或正式评价；
    [ ] 场景生成失败时重采样并记录原因，禁止把不可解地图放入成功率分母。

======================================================================
三、场景递进：先证明可解，再增加障碍复杂度
======================================================================

S0：几何、边界和判据烟雾测试

    [ ] 验证圆柱、Box、Wall 的碰撞体、可视化网格和安全膨胀完全一致；
    [ ] 验证“进入中央区”“到达对侧外部区”“捕获”是三个独立事件；
    [ ] 验证 4 架追捕机和目标都能被正确记录 crossing flag、首次 crossing 时间和终止原因；
    [ ] 用确定性脚本轨迹验证无碰撞路径和非法路径会被正确区分；
    [ ] 不训练、不渲染论文图，先保证判据可信。

S1：固定单类型中央障碍（最小可解基线）

    [ ] S1-Cylinder：中央圆柱，保留两侧可选通道；
    [ ] S1-Box：中央立方体，保留上方或侧方通道；
    [ ] S1-Wall：一面不封死地图的墙体，明确门洞或绕行端点；
    [ ] 对每个单类型布局，先运行 rule expert + CBF 20 回合；
    [ ] 输出一条完整的“目标进入中央区、追捕组拦截并捕获”轨迹，用来验证任务定义；
    [ ] 对同一布局单独运行 Transit Success，验证目标和每架追捕机都有安全通行路线。

S2：固定中央混合障碍（主要展示场景）

    [ ] 布置 1 个圆柱 + 1 个立方体 + 1 面墙体，障碍物只放在中央区；
    [ ] 明确保留至少两条安全通道，避免障碍物把中心区域变成单一路径死锁；
    [ ] 追捕组和目标在障碍区两侧、不同高度/横向位置出生，初始间距 4.5-6.0 m；
    [ ] 目标使用可复现的“向对侧逃逸 + 有限随机转向”运动模型，禁止依赖目标真值的学习策略读取；
    [ ] 通过 S2 后，固定一套最适合展示的布局和 seed，专门输出高质量视频；
    [ ] 该场景必须报告目标/每架追捕机的 zone entry 和 crossing 指标，而不能只展示一次捕获；
    [ ] 另行运行固定 S2 Transit Success，证明障碍布局不是依赖不可通行死角实现拦截。

S3：随机中央混合障碍（泛化主实验）

    [ ] 随机障碍数量 3-5 个，类型来自圆柱、Box、Wall；
    [ ] 随机位置、尺度、高度和通道，但全部限制在中央障碍区；
    [ ] Wall 在现有碰撞模型下只采用物理一致的 0/90 度轴对齐方向；
    [ ] 地图必须满足目标右到左、每架追捕机左到右的独立双向可达性检查和最小通道宽度，
        不允许训练集/测试集出现不可通行迷宫；
    [ ] train、validation、locked-test 使用互不重叠的 layout seed 和 target-motion seed；
    [ ] 保留 S1/S2 作为回归场景，随机化不能掩盖固定场景退化。

S4：困难但仍可解释的扩展（仅 S3 稳定后启动）

    [ ] 一次只加入一个因素：更窄通道、更高障碍、目标更强转向、观测遮挡或通信延迟；
    [ ] 每个因素设置 normal / hard 两档，并与 S3 共享评价协议；
    [ ] 记录失败类别：未完成目标穿越、追捕机未全员穿越、超时、碰撞、越界或未捕获；
    [ ] 本阶段不引入真实飞控和复杂空气动力学，避免研究问题失焦。

======================================================================
四、方法与训练路线
======================================================================

1. 必须保留的对照

    [ ] Dynamic Encirclement rule expert + CBF：验证地图和任务本身可解；
    [ ] 现有 Recurrent MAPPO + CBF：测量旧策略在新分布上的退化；
    [ ] Recurrent Behavior Cloning + CBF：作为课程学习的稳定初始化；
    [ ] BC 初始化的 Recurrent MAPPO + CBF：主学习方法；
    [ ] raw action 和 CBF action 分开报告，不能把 CBF 的安全修正完全归因于策略网络。

2. 是否需要重新训练

    需要。现有 MAPPO 已在反向起点上表现出明显分布外失败，且它没有被训练为
    “中央障碍区相遇捕获 + 独立双向安全通行”这一新任务。只更换渲染或障碍模型
    不能让旧 checkpoint 学会这个任务。重新训练的目标是适配新任务分布，不是为了画面美化。

3. 课程训练顺序

    [ ] C1：Open/单圆柱，目标和追捕机的确定性反向穿越；
    [ ] C2：Cylinder + Box，加入少量横向和高度变化；
    [ ] C3：固定 Mixed S2，加入墙体和有限随机目标转向；
    [ ] C4：双向出生侧均匀采样，防止只学会左到右的单侧策略；
    [ ] C5：随机 Mixed S3，逐步从 3 个障碍增加到 5 个障碍；
    [ ] C6：先训练 BC，再以 BC checkpoint 初始化 Recurrent MAPPO；
    [ ] C7：使用 validation 选择 checkpoint；locked-test 只在模型和超参数冻结后运行；
    [ ] C8：至少 3 个独立训练 seed，不能用单个最好 seed 代表结论。

六、完成标准与停止规则
======================================================================

最低展示完成：

    [ ] 固定 S2 中有可复现的 Showcase Success；
    [ ] 轨迹文件证明目标和至少一架实施捕获的追捕机均已进入中央障碍区；
    [ ] 对应的独立 Transit 轨迹证明目标和 4 架追捕机均可安全到达规定对侧区域；
    [ ] 轨迹文件证明捕获发生于 r_capture = 0.80 m 内且此前无碰撞、无越界；
    [ ] 有对应的 PNG/GIF/MP4 和 episode.json，而非仅有渲染画面。

研究结论完成：

    [ ] S1/S2/S3 均使用冻结的评价协议；
    [ ] 至少 3 个训练 seed 和独立 locked-test；
    [ ] 同时报告捕获、中央区进入、独立通行、安全和失败原因；
    [ ] raw / CBF 分开报告；
    [ ] 结论仅表述为“仿真中的捕获半径成功”，不外推为实体捕获或实飞成功。

停止规则：

    [ ] 若 rule expert 不能通过某场景，先修正地图、可达性或运动学难度；
    [ ] 若专家可解而学习策略失败，才进行课程训练或策略改进；
    [ ] 若 3 个训练 seed 均无稳定提升，记录失败边界并停止堆叠新模块；
    [ ] 仅当 S3 的双向穿越与安全捕获稳定后，才扩展至遮挡、延迟和更困难障碍。
