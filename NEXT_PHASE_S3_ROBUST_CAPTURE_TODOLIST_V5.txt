======================================================================
一、计划目的与研究边界
======================================================================

本计划不是重复 V4 locked-test，而是围绕已发现的 S3 失败补充实验，目标是回答：

    在三维、部分可观测、中央随机混合障碍和持续逃逸目标下，
    Retained BC + CBF 是否能够在延迟噪声、窄通道、障碍数量变化和目标机动下
    稳定完成协同捕获，并且安全性不是由偶然单机接近造成的？

任务合同保持不变：
    - 4 架追捕机对 1 架逃逸目标；三维运动学仿真，不外推为实飞或实体接触捕获。
    - 世界边界、中央障碍区、主体半径、碰撞规则和 r_capture = 0.80 m 保持 V4 冻结值。
    - Capture：任一追捕机进入目标 0.80 m 半径。
    - Safe Capture：首次捕获前无障碍物碰撞、机间碰撞和越界。
    - Cooperative Safe Capture：Safe Capture 且捕获前至少 2/4 架追捕机进入中央区。
    - 目标不要求进入或穿过中央障碍区；Transit 仍是独立通行性实验。

三、下一阶段量化目标与停止条件
======================================================================

主指标：Cooperative Safe Capture Rate。必须同时报告普通 Capture Rate 和 Safe
Capture Rate，不能把 CBF 修正后的结果全部归因于策略网络。

开发 validation 目标（新 seed，不能使用 V4 locked seed 调参）：
    [ ] Cooperative Safe Capture >= 85%。
    [ ] Collision <= 2%，Boundary violation <= 2%。
    [ ] Transit >= 99%。
    [ ] 固定 S1/S2 不退化：每种布局至少 98%，且不得出现连续两次安全回归失败。
    [ ] 相对 Retained BC + CBF，Time-to-Capture、最小净空和路径长度不能出现
        无法解释的恶化；同时报告 CBF correction 分布，而非只报告均值。

最终新 locked-test 目标（模型和超参数冻结后）：
    [ ] 3 个独立训练 seed；每个 seed 使用相同的新 locked 场景块。
    [ ] S3 平均 Cooperative Safe Capture 至少达到 85%，并报告 95% 置信区间；
        若未达到，必须保留 V4 基线并如实记录失败。
    [ ] Collision 和 Boundary 各自 <= 2% 作为安全门槛；Transit >= 99%。
    [ ] 至少提供 nominal 与 delayed_noisy 两组结果，不能只报告容易的 nominal。
    [ ] 所有结论限定为三维运动学仿真中的捕获半径成功。

禁止事项：
    [ ] 不打开或重采样 V4 已使用的 S3 locked seed block（647001）。
    [ ] 不根据 locked-test 结果反向调阈值、地图、CBF 或训练超参数。
    [ ] 不同时引入动态障碍、真实飞控、真实相机和新网络结构；一次只改变一个主因素。
    [ ] 不以单个漂亮视频替代统计结果。

目标：先确认失败发生在“观测、协同决策、动力学安全约束还是时间预算”，再训练。

    [ ] F1.1 从已有 locked artifacts 汇总每个失败 episode 的阶段标签：
          未进入中央区、进入后分散、接近阶段停滞、CBF 强修正、碰撞/越界、timeout。
    [ ] F1.2 将 delayed_noisy、nominal、窄/中净空、3/4/5 障碍、flee_persistence、
          s_curve、左右出生侧分别生成失败回放索引；不修改原始 locked artifacts。
    [ ] F1.3 定义难例筛选规则并写入 YAML：例如 timeout、min_clearance < 0.30 m、
          CBF correction > 0.25 或捕获前 zone-entry 不完整；阈值只能在 validation
          阶段确定，不能用最终 locked-test 调整。
    [ ] F1.4 检查失败是否由时间上限、目标速度或 CBF 安全边界造成；分别记录

    [ ] F1.5 输出 `S3_FAILURE_ANALYSIS_REPORT.md` 和机器可读的 failure_index.json，

F1 通过门槛：每个失败类别都有可复现样本；不能把所有失败笼统标为“策略不稳定”。

六、阶段 F2：单因素策略改进实验
======================================================================

默认从 Retained BC 初始化；每个变体先用 1 个 pilot seed 做 validation，只有通过
固定 S1/S2 门槛才进入 3 seed。每次只改变一个主要因素。

F2-A 难例重采样 BC（优先实验）
    [ ] A1. 用 rule expert + CBF 在 F1 难例分布上生成质量门控演示；专家失败的
          地图记录并剔除，不能把不可解样本当训练数据。
    [ ] A2. 保留原 V4 fixed S1/S2 archive，与 S3 hard archive 做 equal-sequence
          平衡；至少比较 1:1 和 hard-example 2:1 两种比例。
    [ ] A3. 保留 sequence length、observation/action scale、网络结构和优化器，
          避免把数据改动与结构改动混在一起。
    [ ] A4. 记录接受率、拒绝率、左右出生侧、障碍数、观测条件和 archive SHA-256。

F2-B 部分可观测条件增强（第二优先）
    [ ] B1. 只在 F2-A 不足时加入训练时 observation augmentation：delay、dropout、
          noise 分别逐项打开；先使用 V4 范围，再测试更强范围。
    [ ] B2. 至少比较 nominal-only、delayed_noisy-only、mixed 三种数据条件，
          保留完全相同的 S1/S2 回归数据。
    [ ] B3. 不能只通过增加噪声获得“鲁棒”结论；必须分条件报告 nominal 与 delayed_noisy。

F2-C 协同与接近行为诊断（第三优先）
    [ ] C1. 统计每架追捕机的 zone-entry 顺序、捕获前最近距离和最终接近方向，
          检查是否存在单机追击、队形塌缩或过度绕障。
    [ ] C2. 只在证据显示确有协同退化时，增加轻量的 zone-entry/队形保持辅助损失；
          先做有/无辅助损失消融，不直接改捕获半径或强行让目标穿中央区。
    [ ] C3. 辅助损失不得牺牲捕获；若 S1/S2 或最小净空退化，立即拒绝该变体。

F2-D CBF 执行层敏感性（安全诊断，不归因给策略）
    [ ] D1. 在同一冻结策略上报告 raw、CBF-default 和 CBF 候选参数的对照，
          分离策略错误与安全过滤器修正效果。
    [ ] D2. 只在开发 validation 上研究 safety margin、修正量、路径长度和 timeout
          的权衡；最终候选冻结后不得针对 locked-test 调参。
    [ ] D3. 如果 CBF correction 大且捕获率低，优先检查地图可行性和动作饱和，
          不把更强过滤器的低捕获误判为策略改进。

F2-E MAPPO 重新尝试条件（默认不做）
    [ ] E1. 只有 F2-A/F2-B 的 BC 变体在 S3 validation 仍无法达到 85%，且失败归因
          指向长期协同决策时，才启动 MAPPO。
    [ ] E2. MAPPO 必须从合格 BC 初始化并保留行为保持正则；先过固定 S1/S2 raw/CBF
          回归，再进入 S3；任何固定场景退化都拒绝，不再延长训练掩盖退化。

十一、最终完成标准与明确不做事项
======================================================================

研究级补充实验完成必须同时满足：
    [ ] 已解释 V4 S3 失败的主要条件，并有逐回合可复现索引。
    [ ] 至少一个单因素改进在新 validation 达到预设门槛，且 S1/S2 无明显退化。
    [ ] 3 个独立训练 seed 在全新 next-locked-test 上复现，报告均值、方差和置信区间。
    [ ] raw、CBF、Expert 和最佳候选的贡献边界清楚分离。
    [ ] nominal、delayed_noisy、窄净空、障碍数和目标运动模式均有分组统计。
    [ ] 成功与失败媒体和原始轨迹 hash 一致，报告可由仓库配置复现。

本计划暂不包含：
    - 真实无人机飞控、实物碰撞捕获、网捕机构或实体接触实验；
    - 动态障碍物、多目标围捕和真实相机标定；
    - 在 V4 locked-test 上反复调参；
    - 为了画面更好看而改变物理捕获判定；
    - 把目标进入中央区或穿越障碍区设为主捕获条件。

下一步唯一优先动作：
    先完成 F0/F1，建立新的 validation seed block 和 S3 failure index；
    在没有失败归因和新基线 manifest 之前，不启动新的 MAPPO 或大规模训练。
