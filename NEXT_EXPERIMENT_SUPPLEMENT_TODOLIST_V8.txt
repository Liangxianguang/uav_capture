0. 唯一目标与当前判断
======================================================================

唯一研究问题：
    在不改变任务定义的前提下，4 架追捕机能否在三维、部分可观测、中央混合
    静态障碍、持续逃逸目标场景中，稳定完成安全协同捕获？

本轮要证明的是可重复的统计结论，而不是一条好看的成功视频：
    1. policy + CBF 能否在随机 S3 地图稳定捕获；
    2. 改善是否来自可复现的数据/训练改动，而非改阈值、换场景、挑视频；
    3. 固定回归、随机场景、困难分组和独立 locked-test 是否同时成立。

已知结果（不重复运行）：
    [x] V4 正式基线已经完成 3 seed S3 locked-test（647001）：
        retained-BC + CBF Cooperative Safe Capture = 75.3% +/- 6.5%；
        raw actor = 2.3% +/- 1.2%，因此 CBF 是正式执行栈的一部分。
    [x] V5 fresh baseline（661401）失败：
        固定 CBF Cylinder/Box/Wall/S2 = 35%/45%/50%/45%；
        S3 + CBF = 41/60 = 68.3%，Collision/Boundary = 0%，Transit = 100%，
        主要失败为 timeout。
    [x] 契约审计表明 fresh baseline 没有继承 V4 固定 archive、等序列平衡和
        warm start，不能称为 faithful retained-BC 复刻。
    [x] P2-0.1 archive 混合恢复被拒绝：
        固定 CBF = 20%/95%/100%/90%，S3 + CBF = 30/60 = 50%；
        原因是未恢复完整的 shape-aware fixed stage + warm start。
    [x] 完整 P2-0.2 的代码/YAML/启动脚本已提交（a17f667）。
    [ ] P2-0.2 尚未运行：
        results/central_v5/fixed_shapeaware_seed661601 不存在；
        results/central_v5/shapeaware_retained_seed661602 不存在。

当前决定：
    V5 尚未完成，不能宣称超过或稳定复现 V4。先完成 P2-0.2，再按失败证据只选
    一个单因素分支；现在不引入 MAPPO、动态障碍、真实视觉或复杂动力学。

1. 冻结的实验合同
======================================================================

[ ] 4 pursuers + 1 evader；捕获半径 r_capture = 0.80 m。
[ ] Cooperative Safe Capture：首次捕获前无障碍/机间碰撞、无越界，且至少 2/4
    追捕机进入中央障碍区域。目标无需进入中央区域。
[ ] 环境：三维运动学、圆柱/立方体/墙体静态障碍、边界、固定 episode horizon。
[ ] 观测：只使用已有合成部分可观测条件（nominal、delay/noise/dropout 等），
    不得称为真实相机感知。
[ ] 必报：Capture、Safe Capture、Cooperative Safe Capture、Collision、Boundary、
    Timeout、Transit、Time-to-Capture、最小净空、每架路径长度、CBF correction。
[ ] raw actor 与 policy + CBF 分开评估/报告；必须使用相同 checkpoint、静态地图、
    初始状态、目标 profile 和 episode seed。
[ ] V5 development = 646101；V5 locked-test = 647201；V4 historical locked =
    647001。647201、647001 禁止用于训练选择、超参数选择或 CBF 调参。
[ ] 不改 r_capture、2/4 条件、碰撞/边界规则、episode horizon 或 CBF 默认值来提高
    成功率。CBF 参数实验只能用于冻结 checkpoint 的执行诊断。

5. P3：失败驱动的单因素补充（只能选一个分支）
======================================================================

共同规则：
    每次只改一个主因素，先用 1 个 development pilot seed；其他 YAML、训练总预算、
    capture 定义、horizon、评估 seeds 与 CBF-default 不变。候选未过门槛即写
    rejection report，禁止叠加多个“可能有效”的改动。

P3-A 固定覆盖（仅固定回归失败）
[ ] 将 fixed archive 按 layout、初始距离、每架 zone entry、捕获时间、最小净空、
    动作范数分桶，定位唯一退化类型。
[ ] 只补足该类型的合格 expert demonstration，使固定 layout sequence 数处于预写
    均衡区间；random archive、warm-start、优化器不变。
[ ] 先重跑固定回归；四项均 >= 98% 才能重跑 S3。

P3-B 难例重采样/质量门控 BC（仅 S3 timeout 为主）
[ ] rule expert + CBF 生成可行 hard archive：narrow clearance、5 obstacles、
    s_curve、远初始距离。expert 无法安全捕获的地图标为 infeasible，不进入训练。
[ ] 固定 P2 通过的 fixed archive；仅对 random portion 比较 normal:hard = 1:1 与
    1:2，且 random sequence 总数和优化步数相同。
[ ] 记录接受率、左右出生侧、layout、速度、运动模式、拒绝原因，避免偏向简单通道。
[ ] 只有 hard-group timeout 下降且固定回归不退化的版本可进入 P4。

P3-C 观测鲁棒性（仅 delayed_noisy 明显更差）
[ ] 先做 nominal-only、delay-only、noise-only、dropout-only 诊断，确认主扰动源。
[ ] 一次只加入一种增强，顺序 delay -> noise -> dropout；比较 nominal-only、
    target-condition-only、mixed，训练样本数与优化步数一致。
[ ] 同报 nominal 和 delayed_noisy；困难组提高但 nominal 或固定回归下降即拒绝。

P3-D 轻量协同辅助项（仅协调失败而非安全失败）
[ ] 从轨迹计算 zone-entry 顺序、agent-agent distance、目标距离、最终接近方位、
    队形离散度、CBF correction 时间序列。
[ ] 只新增一个可解释辅助项（如 zone-entry coverage 或接近方位分散），做 0/1
    消融；不改 capture 判定，不加入 MAPPO。
[ ] 同报 Capture、最小净空、correction、path length；任何安全/固定回归退化即拒绝。

P3-E CBF 执行诊断（仅碰撞/越界为主）
[ ] 冻结 checkpoint，只比较 raw、CBF-default、少量预注册 safety margin；不重训，
    不用 locked-test 选 margin。
[ ] 报告 Collision、Boundary、Timeout、Transit、最小净空、Time-to-Capture、
    path length、correction mean/median/P95。
[ ] 选定一个参数后冻结；CBF 是执行安全层，不表述为学习算法性能提升。

MAPPO 启动门槛：
    仅 P3-A/P3-B/P3-C 都失败，且 P3-D 证明问题是长期协同决策而非专家数据、观测、
    窄通道或 CBF 时，才单开“BC-initialized MAPPO”新课题。必须有行为保持正则、
    相同预算基线和独立预注册，不与 V5 retained-BC 主结论混写。
