下一阶段研究计划书（理论仿真主线版）
题目：部分可观测三维障碍环境下的多无人机协同捕获
版本：2026-08-19

======================================================================
一、研究定位：现在做什么，不做什么
======================================================================

1. 当前可成立的研究目标

在三维障碍环境中，4 架防守无人机仅根据局部观测、历史信息和受限队友通信，
协同追捕 1 个高机动逃逸目标；当任一防守无人机首次进入捕获半径时判定 Capture，
且此前没有碰撞或越界时判定 Safe Capture。

下一阶段的核心问题是：

    面对观测时延、连续遮挡和消息不可靠，如何构造时间一致的目标 belief，
    并让协同策略依据 belief 的不确定度稳定完成三维捕获？

这是一项完全可以用可控仿真完成的理论研究。训练和测试数据均可由仿真器生成，
不以实飞平台、真实飞控日志、真实视觉数据或公开视频数据集为前提。

2. 明确不作为当前主线的内容

[x] 不把捕获半径外推为网捕、机械抓取或实体捕获。
[x] 不声称已完成真实相机、LiDAR、完整飞控或实飞验证。
[x] 不因缺少实飞数据而暂停主线；当前缺少的是高保真外部验证，不是理论结论的核心证据。
[x] 不直接堆叠更大的网络、端到端视觉输入或完整空气动力学，以掩盖当前失败原因。
[ ] PyBullet、SITL、真实检测跟踪和实飞仅作为以后有平台和数据时的独立扩展，
    不进入本阶段完成标准。

3. P1 给出的研究切入点

[x] 正常部分可观测条件下，D/E raw Safe Capture 分别为 91.33% / 91.00%。
[x] 延迟测量下，D/E raw Safe Capture 降至 63.33% / 54.67%；E-D 为
    -8.67 +/- 8.72 个百分点。
[x] 突发遮挡下，D/E raw Safe Capture 均为 61.67%。
[x] 通信丢包下，D/E raw Safe Capture 为 81.67% / 86.33%，但置信区间跨 0。
[x] 时延和突发遮挡明显增大 Observation Age，并同时降低 raw 与 CBF 的捕获表现。

结论：当前 GRU 预测没有稳定提高部分可观测鲁棒捕获。下一步应研究“时延补偿和
遮挡恢复”，而不是重复训练更多相同的预测网络，也不需要为了这个问题先做实飞。

三、固定任务、成功判据和研究假设
======================================================================

1. 固定任务

- 防守无人机：4 架；逃逸目标：1 个；捕获半径 r_capture = 0.80 m。
- 障碍：圆柱、方盒、墙体、窄通道和混合布局。
- 目标：直线逃逸、随机转向、S 曲线、持续转向、边界诱导和高机动组合。
- 执行观测：每架无人机只使用本机局部观测、历史 belief 和可获得的队友消息。
- centralized critic 只在训练时使用全局状态；部署策略禁止读取目标隐藏真值。

2. 事件判据与必报指标

Capture：min_i ||p_i - p_target|| <= r_capture。

Safe Capture：首次 Capture 前未发生无人机-障碍物碰撞、无人机-无人机碰撞或边界越界。

必报：Safe Capture Rate、Capture Rate、Collision Rate、Boundary Violation Rate、
Time-to-Capture、Minimum Clearance、Target Visibility、Observation Age、Message Age、
Packet Loss、目标状态估计误差和 CBF Correction Magnitude。

视频和截图只用于展示，最终结果以事件日志、冻结配置和 locked-test 统计为准。

3. 下一阶段研究假设

H1：对带时间戳的延迟观测进行时间对齐与固定滞后更新，比直接把陈旧观测送入策略
    更能降低目标 belief 在遮挡和时延下的误差。

H2：将 belief 的年龄、协方差或不确定度和可见性显式输入循环策略，使策略知道
    “当前目标位置有多可信”，可降低盲目追击带来的碰撞和捕获失败。

H3：上述改进若有效，应主要体现在延迟测量与突发遮挡域；若在常规域没有提升而在
    困难域稳定改善，仍是有价值且边界清晰的理论结论。

四、唯一主线：时延补偿与遮挡恢复
======================================================================

阶段 A：失败诊断与测试协议冻结

[x] A1. 从 P1 的 delayed_measurements 与 burst_occlusion 中各选择 20 条失败轨迹，
    按“观测陈旧、重获观测、错误预测、障碍碰撞、队友协同失配”标注失败原因。
[ ] A2. 冻结两组主测试域：中等时延和强时延；短时遮挡和突发遮挡。
    每组保留固定 locked-test seed，训练/验证/test seed 继续严格分离。
[x] A3. 先在现有 D/E 冻结策略上计算目标位置/速度误差随 Observation Age 的曲线，
    确认方法要解决的是 belief 误差，而不是奖励或场景生成器缺陷。

阶段 B：最小可解释方法

[ ] B1. 实现“时间对齐 target belief”模块：保存有限历史状态；收到带时间戳的延迟观测时，
    在其对应时刻更新，再传播至当前时刻。
[ ] B2. 输出 belief 均值、速度、协方差或等价不确定度、观测年龄、可见性和消息年龄；
    所有输出只能由局部观测与允许通信构成。
[ ] B3. 实现简单、可解释的基线：零速度外推、常速度外推、时间对齐的固定滞后 belief。
    在相同轨迹上比较位置误差、速度误差和重获观测后的恢复时间。
[ ] B4. 为消息融合保留时间戳和来源，不允许使用未来信息或目标真值；新增真值泄漏测试。

阶段 C：不确定度感知的协同捕获策略

[ ] C1. 在 D 的 Recurrent-MAPPO 输入中接入 B 阶段的 belief 特征，形成 F：
    Belief-aware Recurrent-MAPPO；先保持网络规模和奖励主体不变。
[ ] C2. 仅在验证集决定模型选择、特征归一化和训练轮数；不根据 locked-test 调参。
[ ] C3. 训练 F 的 3 个独立 seed；保留 effective YAML、源码 hash、checkpoint、
    GPU/依赖信息和 TensorBoard 曲线。
[ ] C4. 采用逐项消融：
    D：Recurrent-MAPPO；
    E：D + 现有 GRU prediction；
    F1：D + 时间对齐 belief；
    F2：F1 + 不确定度/年龄特征。
    若 F1 没有说明性收益，不继续增加 F2 或更复杂模块。

阶段 D：正式评估与结论

[ ] D1. 在常规、时延、突发遮挡和通信丢包四个冻结测试域评估 D/E/F1/F2；
    raw action 与 CBF action 分开评估。
[ ] D2. 每种方法使用至少 3 个独立训练 seed；每个主要测试域每个 seed 至少 100 回合，
    以训练 seed 为统计重复单位，报告均值、标准差、95% Student-t CI 和配对差值。
[ ] D3. 报告捕获安全指标与 belief 指标的对应关系：例如 Observation Age、估计误差、
    重获观测恢复时间、最小间距和 CBF 修正量。
[ ] D4. 只在至少 2/3 训练 seed 同方向改善、置信区间和失败轨迹给出一致证据时，
    表述为“在指定困难域改善”；否则如实报告失败边界。
[ ] D5. 输出一份正式报告、结构化 JSON、代表性成功/失败三维轨迹和可复现命令。
