下一阶段实验计划书（修订版）
主题：部分可观测障碍环境下多无人机协同三维捕获
版本：2026-08-19

======================================================================
一、研究目标与边界
======================================================================

1. 总体目标

在三维障碍环境中，使用多架防守无人机协同追踪高机动逃逸目标。每架无人机只能使用局部观测、历史信息和受限队友通信；当目标被遮挡、漏检、观测延迟或通信受限时，系统仍应尽可能稳定地完成捕获，并避免撞击障碍物、队友和环境边界。

2. 最终研究问题

“预测增强的记忆型多智能体策略，能否在部分可观测和受限通信的三维障碍环境中，提高多无人机的安全捕获率与鲁棒性？”

3. 推荐方法主线

学习式轨迹预测
    + belief state（目标状态、置信度、观测年龄和不确定度）
    + Recurrent-MAPPO（GRU/LSTM 记忆）
    + 局部 CBF 安全过滤器

4. 研究边界（必须遵守）

[ ] 论文主结论只基于可控、可复现的三维仿真，不宣称已经完成实飞、SITL、真实视觉闭环或实体网捕。
[ ] 预测器训练数据由仿真器生成即可，不把“没有真实飞行数据”当作当前主线的阻塞条件。
[ ] RGB-D、LiDAR、真实相机标定和完整飞控模型属于后续扩展，不作为当前阶段的硬性依赖。
[ ] PyBullet 只作为附加动力学验证；若迁移工作量阻塞核心实验，应将其列为未来工作。
[ ] 旧四面体空间约束、软体网和实体接触实验保留为历史探索，不与本计划的捕获半径结果混合统计。

二、统一任务定义与成功判据
======================================================================

1. 主任务

- 防守无人机数量：4 架；逃逸目标数量：1 个。
- 环境：20 m × 20 m × 10 m 三维空间，可配置障碍物、遮挡和边界。
- 捕获半径：r_capture = 0.80 m。
- 策略输入：局部目标观测、局部障碍信息、队友消息、历史记忆和 belief state。
- centralized critic 只在训练阶段读取全局状态；执行阶段禁止使用隐藏真值。

2. 统一指标

Capture：
    min_i ||p_i - p_target|| <= r_capture。

Safe Capture：
    发生 Capture，且在首次捕获前没有无人机-障碍物碰撞、无人机-无人机碰撞或边界越界。

必须报告：

- Safe Capture Rate
- Capture Rate
- Collision Rate
- Boundary Violation Rate
- Time-to-Capture
- Minimum Clearance
- Target Visibility
- Communication Age
- Prediction Error
- CBF Correction Magnitude

说明：视频和截图只用于展示，不能作为成功判据；所有结论以事件日志和统计结果为准。可额外报告“连续 N 个时间步保持在捕获半径内”的持久捕获指标，但不能替代上述主判据。

五、阶段 3：轨迹预测与记忆型协同捕获（论文核心，必须完成）
======================================================================

目标：利用已有轨迹预测研究基础，改善目标暂时不可见、通信延迟和高机动造成的追踪失效。

1. 预测器

[x] 使用仿真历史观测生成预测器数据集；按场景 seed block 划分 train/validation/locked_test，禁止轨迹泄漏。
[x] 保留 constant-velocity predictor 作为最弱基线，并与 zero-velocity 基线比较。
[x] 训练独立 GRU 学习式预测器；输入只使用局部历史观测及其置信度，不使用隐藏目标真值。
[x] 输出多个未来时域的目标位置分布均值和不确定度。
[ ] 统一预测接口，兼容 MAPPO、Recurrent-MAPPO、CBF 和评估脚本。

2. 记忆型协同策略

[ ] 将 MLP actor 替换为 GRU/LSTM actor，输入最近 K 帧观测、预测结果、置信度和消息年龄。
[ ] 使用参数共享的 Recurrent-MAPPO；critic 仅在训练期使用 centralized state。
[ ] 采用课程训练：开阔环境 -> 障碍环境 -> 遮挡/漏检 -> 通信受限 -> 高机动目标。
[ ] 同时保存 raw action 和 CBF 过滤后的 action，分别统计，避免混淆策略收益与安全层收益。

3. 必做消融

[ ] MAPPO（无预测、无记忆）
[ ] MAPPO + constant-velocity prediction
[ ] MAPPO + learned prediction
[ ] Recurrent-MAPPO（无学习式预测）
[ ] Recurrent-MAPPO + learned prediction
[ ] 上述方法分别测试 raw action 与 +CBF action
