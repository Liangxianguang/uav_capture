下一阶段实验计划书（理论研究可复现版）
主题：部分可观测障碍环境下多无人机协同三维捕获
版本：2026-08-19

======================================================================
一、研究目标与边界
======================================================================

1. 研究目标

在三维障碍环境中，4 架防守无人机仅利用本机局部观测、有限历史信息和
受限队友通信，协同追踪并捕获 1 个高机动逃逸目标。研究重点不是复现某个
特定实飞系统，而是回答下列可检验的理论问题：

- 遮挡、漏检、观测延迟和通信不稳定时，轨迹预测能否提高闭环捕获能力？
- 历史记忆能否减轻陈旧观测和连续失联造成的决策退化？
- 在动作延迟、跟踪误差和参数扰动下，策略能否仍保持稳定、安全的捕获？
- 预测、循环记忆和 CBF 安全层各自贡献什么，又在哪些条件下失效？

2. 论文可以成立的最小结论

在预先锁定的部分可观测三维障碍测试集上，经过多训练种子重复和统计检验，
给出一种能够稳定完成“进入捕获半径”的多无人机协同策略，并清楚分离预测、
记忆与安全过滤对 Safe Capture、碰撞和越界的影响。

3. 当前研究边界

[x] 本研究的主结论基于可控、可复现的三维仿真；训练数据可全部由仿真器生成。
[x] 没有实飞平台、真实飞控日志或真实视觉数据，不构成当前理论研究的阻塞。
[x] 参数化噪声、遮挡、延迟和控制误差用于研究鲁棒性，不等同于真实相机、
    RGB-D、LiDAR 或完整视觉闭环系统。
[x] 仿真中的捕获半径只表示拦截/接触条件，不外推为网捕、实体抓取或实飞捕获。
[ ] PyBullet、SITL 和实飞属于后续附加验证；它们不能取代本计划中的统计仿真结论。

======================================================================
二、固定任务定义与成功判据
======================================================================

1. 固定任务

- 防守无人机：4 架；逃逸目标：1 个。
- 世界范围：20 m x 20 m x 10 m。
- 障碍物：圆柱、方盒、墙体、窄通道和混合布局。
- 目标模式：直线逃逸、随机转向、S 曲线、持续转向、边界诱导和高机动组合。
- 捕获半径：r_capture = 0.80 m。
- 执行阶段：每架无人机只能使用自身局部观测、历史 belief 和可获得的队友消息。
- centralized critic 仅在训练阶段读取全局状态；执行阶段禁止读取目标隐藏真值。

2. 事件判据

Capture：
    min_i ||p_i - p_target|| <= r_capture。

Safe Capture：
    在首次 Capture 之前，未发生无人机-障碍物碰撞、无人机-无人机碰撞或边界越界。

Persistent Capture（附加指标）：
    至少 1 架无人机连续 N 个时间步保持在捕获半径内。

说明：视频和截图只用于定性展示；最终结论以事件日志和 locked-test 统计结果为准。

3. 必报指标

- Safe Capture Rate、Capture Rate、Collision Rate、Boundary Violation Rate。
- Time-to-Capture、Minimum Clearance。
- Target Visibility / Observation Age、Communication Age / Packet Loss。
- Prediction Error、CBF Correction Magnitude。

[x] 生成正式报告、聚合 JSON、失败案例和可复现运行命令。

P1：部分可观测鲁棒性压力测试（核心理论扩展）

目标：不新增真实数据依赖，只改变可控的观测与通信条件，定位方法在哪些
难度下获益、在哪些难度下失效。

[x] 基于冻结的 D、E 策略完成首轮代表性压力测试：
    可见性 {正常、短时遮挡、连续遮挡}；
    漏检率 {低、中、高}；
    观测延迟 {低、中、高}；
    通信 {可靠、延迟、丢包}。
[x] 每个压力条件使用固定 test seed block；4 个代表性条件、3 个训练 seed、
    每条件 100 回合，raw/CBF 均已评估。
[x] 除成功率外，报告 Target Visibility、Observation Age、Message Age、Minimum Clearance 和碰撞率。
[x] 已生成正式报告与结构化结果：
    results/RECURRENT_POLICY_STAGE3C_P1_STRESS_REPORT.md
    results/RECURRENT_POLICY_STAGE3C_P1_STRESS_SUMMARY.json
[x] 首轮结果显示：延迟测量条件下 E raw 相对 D 为 -8.67 +/- 8.72 个百分点；
    突发遮挡为 0.00 +/- 6.57 个百分点；通信丢包为 +4.67 +/- 14.56 个百分点；
    所有差异的 95% CI 均跨 0，不能声称 GRU 已稳定提高鲁棒捕获。
[x] 结果同时表明：延迟和突发遮挡会显著降低 D/E 的 raw 与 CBF Safe Capture，
    而通信丢包条件下 CBF 仍接近 100%；后续应优先研究时延补偿和遮挡恢复。
[ ] 扩展为全难度网格前，先固定并分析代表性失败轨迹；避免组合数量失控。
[ ] 重点分析遮挡后首次重获观测、连续失联和预测不确定度升高时的失败轨迹。
[x] 若预测未提高最终 Safe Capture，已同时报告其对失败模式和最小间距的影响；
    不事后修改主要成功指标。

P2：轻量执行误差与动力学鲁棒性（仍然完全可在本地完成）

目标：验证阶段 3 的结论是否依赖“动作瞬时、精确执行”的理想运动学假设，

[ ] 增加动作延迟、速度/加速度限制、控制噪声和一阶速度跟踪误差。
[ ] 在训练时对最大速度、加速度、阻尼和等效质量进行范围随机化；

[ ] 在未见过的扰动组合上评估冻结策略，并与无扰动运动学结果单独并列报告。
[ ] 记录 desired action、executed action、动作误差、最小间距和 CBF 修正幅度。
[ ] 先做 1 个最小扰动模型和 1 个强扰动测试域；只有结论仍清晰时才继续增加参数。

五、最小消融矩阵与停止规则
======================================================================

| 编号 | 策略 | 学习式预测 | 循环记忆 | CBF |
| A | MAPPO | 无 | 无 | 关/开 |
| B | MAPPO | 常速度 | 无 | 关/开 |
| C | MAPPO | GRU | 无 | 关/开 |
| D | Recurrent-MAPPO | 无 | GRU actor | 关/开 |
| E | Recurrent-MAPPO | GRU | GRU actor | 关/开 |

所有对比使用相同环境版本、奖励、训练步数、评估协议和测试 seed block。
先完成 D/E 的正式统计，再冻结 A/C/D/E 进入 P1；不要在主方法尚未稳定时并行
叠加更多网络、视觉输入或完整动力学。

继续扩展一个模块的参考条件：

- 核心方法在预先锁定的困难域上相对对应基线取得有解释力的改进，或揭示了
  清晰、可重复的失败边界；
- 至少 3 个训练 seed 中 2 个呈同方向变化；
- 捕获率改进不以明显更高的 Collision Rate 或 Boundary Violation Rate 为代价；
- 结论可由事件日志、配置、checkpoint 和固定 seed 重现。

若不满足上述条件，优先分析奖励、课程、观测编码、预测不确定度和失败轨迹，
不通过增加复杂模块或转向实飞来掩盖不确定结论。
