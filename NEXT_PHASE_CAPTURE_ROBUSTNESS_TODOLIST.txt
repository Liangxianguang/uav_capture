下一阶段：复杂环境下多无人机稳定围捕 TODO 计划

总目标
[ ] 在当前“4 架无人机 + 1 个目标 + 三维障碍 + 部分观测 + 捕获半径”的闭环上，逐步加入更复杂目标、更复杂障碍、更真实动力学和真实感知误差。
[ ] 保持捕获定义不变：至少一架无人机进入 r_capture=0.80 m；捕获前不得发生无人机-障碍物、无人机-无人机碰撞或越界。
[ ] 所有结果分开报告：kinematic、PyBullet dynamics、perception-in-the-loop；不得合并成一个成功率。

阶段 0：冻结当前基线（必须先完成）
[ ] 保存当前三种训练种子、900 回合锁定测试集、checkpoint SHA256、配置和源码 hash。
[ ] 固定随机数、测试场景生成器和指标脚本；测试集只允许读取，不允许调参。
[ ] 记录基线：Safe Capture、Collision、捕获时间、最小间距、越界率、目标可见率。
[ ] 完成一次“从源码重新训练/评估”的复现，确认结果仍为 100% Safe Capture、0% Collision。

阶段 1：目标复杂度（先不改变感知接口）
[ ] 增加目标速度分层：0.55、0.75、1.00、1.25 倍基线速度。
[ ] 增加目标机动模式：定向逃逸、随机航向切换、S 型机动、加减速、边界诱导逃逸。
[ ] 增加目标动力学随机化：最大加速度、转向时间常数、速度噪声、短时突发机动。
[ ] 增加多目标干扰场景，但先保持“一个真实目标 + 0~2 个诱饵目标”的评估定义。
[ ] 通过后门真值接口检查策略是否真正使用局部观测，而不是泄漏目标真值。
[ ] 阶段门槛：每种目标模式至少 100 个锁定回合；Safe Capture >= 90%，Collision <= 5%。

阶段 2：障碍物和地图泛化
[ ] 将固定圆柱扩展为随机圆柱、箱体、墙段、窄通道和组合障碍。
[ ] 训练/测试分离地图生成器：测试地图不得与训练地图复用随机种子。
[ ] 增加未知障碍：策略只能获得局部障碍观测，不提供全局地图。
[ ] 加入障碍物观测丢失、测距噪声和障碍物位置延迟。
[ ] 评估障碍密度、最窄通道宽度、遮挡比例和可见区域比例。
[ ] 阶段门槛：未见地图 300 回合，Safe Capture >= 85%，Collision <= 5%，越界率 <= 2%。

阶段 3：真实动力学迁移（PyBullet）
[ ] 用当前 kinematic 策略作为冻结 teacher，不在测试集上选择 checkpoint。
[ ] 先完成 PyBullet 位置/PID 响应校准：延迟、速度响应、加速度上限、垂向制动。
[ ] 打开动作延迟、速度跟踪误差、质量/阻力随机化、风扰动和控制丢包。
[ ] 使用行为克隆或 DAgger 将局部观测策略迁移到 PyBullet，再进行 MAPPO 微调。
[ ] 记录 commanded action 与 executed action，区分策略失败和执行器失败。
[ ] 阶段门槛：固定动力学配置 100 回合 Safe Capture >= 80%；随机动力学 300 回合 >= 70%；Collision <= 5%。

阶段 4：真实感知闭环
[ ] 建立 RGB-D/深度相机或 LiDAR 的三维观测接口；先使用仿真真值渲染，再加入传感器噪声。
[ ] 将已有目标检测/跟踪模型输出统一为：位置、速度、置信度、时间戳、协方差。
[ ] 用检测丢失、遮挡、误检、漏检和时间延迟生成观测序列。
[ ] 用已有轨迹预测模型替换当前 constant-velocity predictor；保留同一 belief-state 接口。
[ ] 增加目标身份保持和多目标数据关联，避免诱饵切换导致错误围捕。
[ ] 阶段门槛：感知闭环 300 回合，Safe Capture >= 70%；严重误检场景不高于 10% Collision。

阶段 5：策略升级与安全约束
[ ] 将当前 MLP actor 扩展为 GRU/LSTM actor，输入最近 K 帧局部观测和消息年龄。
[ ] 加入 attention/通信门控，比较固定通信、延迟通信和通信丢失下的性能。
[ ] 使用 curriculum：开阔场景 -> 障碍 -> 遮挡 -> 动力学随机化 -> 感知闭环。
[ ] 保留 CBF/安全过滤器作为独立执行层，并报告 raw action 与 CBF action 两行消融结果。
[ ] 比较 MAPPO、Recurrent-MAPPO、QMIX/VDN 或图注意力策略；不以单次最好结果替代多种子结果。
[ ] 奖励只辅助训练，最终成功必须由几何捕获事件和安全约束判定。

阶段 6：严格实验与论文证据
[ ] 每个主结论至少使用 3 个训练种子、300 个锁定测试回合。
[ ] 建立统一 CSV/JSON 指标：Safe Capture、Capture、Collision、Boundary Violation、Time-to-Capture、Minimum Clearance、Visibility、Communication Age。
[ ] 做以下消融：无预测/有预测、无 CBF/有 CBF、无记忆/GRU、无障碍/未知障碍、kinematic/PyBullet、真值感知/噪声感知。
[ ] 画出三维轨迹、捕获半径、障碍物、目标可见性和最小间距曲线；视频只作为可视化，不作为成功判据。
[ ] 保存配置、源码 hash、checkpoint hash、环境版本、GPU 信息和测试种子。
[ ] 明确论文边界：仿真捕获半径 ≠ 实体碰撞捕获；PyBullet ≠ SITL；感知仿真 ≠ 真实相机部署。

推荐执行顺序
[ ] 先完成阶段 0，再做阶段 1 和阶段 2。
[ ] 阶段 1/2 达标后再进入阶段 3，不要同时改变目标、地图、动力学和奖励。
[ ] 阶段 3 稳定后接入阶段 4 的感知误差，最后再做阶段 5 的网络升级。
[ ] 每完成一个阶段，生成一份独立报告和一个冻结 checkpoint，再进入下一阶段。
