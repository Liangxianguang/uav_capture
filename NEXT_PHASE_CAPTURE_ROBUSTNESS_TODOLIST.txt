下一阶段研究计划书（理论仿真主线）
题目：部分可观测三维障碍环境下多无人机协同捕获
版本：2026-08-19

======================================================================
一、研究目标与边界
======================================================================

1. 研究目标

在三维障碍环境中，4 架防守无人机仅利用本机局部观测、历史信息和受限队友通信，
协同追捕 1 个高机动逃逸目标。任一防守机首次进入目标捕获半径时记为 Capture；
若此前未发生障碍物碰撞、机间碰撞或边界越界，则记为 Safe Capture。

本阶段要回答的唯一核心问题是：

    在观测时延、连续遮挡和通信不可靠条件下，时间一致的目标 belief 及其
    不确定度信息，能否提高多无人机协同 Safe Capture 的稳定性？

研究定位：这是一个可控、可重复的理论仿真研究。所有训练数据和测试场景均由
仿真器生成；结论仅适用于本文冻结的运动学、观测模型、通信模型和障碍场景，不把
仿真结果表述为实体捕获、真实视觉闭环或实飞结果。

2. 本阶段不做的事情

[x] 不将“进入捕获半径”外推为网捕、机械抓取、接触动力学或实体捕获成功。
[x] 不把没有实飞数据的限制当成停止理论研究的理由。
[x] 不以 PyBullet、SITL、真实相机、LiDAR、飞控日志或公开视频数据作为本阶段前提。
[x] 不通过堆叠更大网络、端到端视觉或完整空气动力学来掩盖时延/遮挡导致的失败。
[ ] 轻量执行误差与 sim-to-sim 只作为主线结果稳定后的附加验证，不计入本阶段完成标准。

[x] 阶段 3A/3B：GRU 预测相对无预测的 raw-action Safe Capture 平均变化为

3. 已定位的科学问题

[x] 正常部分可观测条件下，D/E 的 raw Safe Capture 分别为 91.33% / 91.00%。
[x] 延迟测量下，D/E 降至 63.33% / 54.67%；突发遮挡下，两者均为 61.67%。
[x] 通信丢包下，D/E 为 81.67% / 86.33%，但置信区间跨 0。
[x] 时延和突发遮挡会增大 Observation Age，并同步降低 raw 与 CBF 的捕获表现。

阶段性结论：现有 GRU 预测并未稳定提高部分可观测鲁棒捕获。下一步应直接研究
“如何正确使用陈旧观测并在遮挡后恢复目标 belief”，而不是重复训练同类预测网络。

三、固定任务、判据与研究假设
======================================================================

1. 固定任务

- 防守无人机：4 架；逃逸目标：1 个；捕获半径 r_capture = 0.80 m。
- 障碍布局：圆柱、方盒、墙体、窄通道和混合布局。
- 目标行为：直线逃逸、随机转向、S 曲线、持续转向、边界诱导和高机动组合。
- 执行观测：每架无人机只使用局部观测、历史 belief 和可获得的队友消息。
- centralized critic 只在训练时使用全局状态；部署 actor 禁止读取目标隐藏真值。

2. 事件判据与必报指标

Capture：min_i ||p_i - p_target|| <= r_capture。

Safe Capture：首次 Capture 前未发生无人机-障碍物碰撞、无人机-无人机碰撞或边界越界。

每次正式评估必须报告：Safe Capture Rate、Capture Rate、Collision Rate、
Boundary Violation Rate、Time-to-Capture、Minimum Clearance、Target Visibility、
Observation Age、Message Age、Packet Loss、目标状态估计误差和 CBF Correction Magnitude。

视频和截图只用于直观展示；最终结论只能由冻结配置、事件日志和 locked-test 统计支持。

3. 可检验假设

H1：对带时间戳的延迟观测进行时间对齐和固定滞后更新，相比直接使用陈旧观测，
    能降低遮挡与时延场景中的目标 belief 误差和重获观测恢复时间。

H2：将 belief 的年龄、协方差/不确定度和可见性提供给循环策略，可让策略识别
    目标状态的可信程度，从而减少盲目追击造成的碰撞和捕获失败。

H3：若方法有效，其收益应主要出现在时延与突发遮挡域。常规域不提升而困难域
    稳定提升，仍是有价值且边界明确的理论结论。

四、主线任务清单
======================================================================

阶段 A：冻结问题与失败证据

[x] A1. 从 P1 的 delayed_measurements 与 burst_occlusion 中各抽取 20 条失败轨迹，
    标注观测陈旧、重获观测、错误外推、障碍碰撞和协同失配等失败链条。
[x] A2. 冻结四个正式测试域：常规、时延、突发遮挡、通信丢包；训练、验证与
    locked-test seed 必须继续严格分离。
[x] A3. 在冻结 D/E 策略上建立“Observation Age - 位置/速度误差 - 事件结果”的对应关系，
    证明后续模块解决的是 belief 误差而非奖励函数或场景生成缺陷。

阶段 B：最小、可解释的 belief 改进

[x] B1. 实现时间对齐 target belief：保存有限历史状态；收到带时间戳的延迟观测时，
    在观测发生时刻更新，再传播至当前时刻。
[x] B2. belief 输出只包含可由局部观测和允许通信推得的信息：均值、速度、
    对角协方差或等价不确定度、观测年龄、可见性、消息年龄。
[x] B3. 实现零速度外推、常速度外推、时间对齐固定滞后 belief 三种可解释基线，
    并比较位置/速度误差、重获观测恢复时间。
[x] B4. 消息带有时间戳和来源；新增单元测试，禁止未来信息和目标真值泄漏。
[x] B5. 在独立 validation seed 上选择“观测年龄门控的速度衰减”，并在新的
    locked-test seed 上复验其同时改善包到达误差和长陈旧观测误差的能力。

阶段 B 已锁定的结论：未经门控的常速度时间对齐只改善观测包到达瞬间误差，
在长陈旧观测下会发散；年龄门控的速度衰减保留短时延收益并限制长时外推误差。
因此，门控时间对齐 belief 可以作为 F1 的唯一新增策略侧信息；不再改变奖励或网络规模。

阶段 C：策略是否真正从 belief 受益

[x] C1. 已完成 F1 配置与 pilot：F1 = D + 门控时间对齐 belief；actor 输入维度、
    奖励、网络大小、CBF 和训练场景分布均与 D 保持一致。pilot 仅用于确认训练链路，
    不作为正式结果。
[x] C2. 冻结 F1 的 effective YAML、特征归一化、训练步数和模型选择规则；这些选择
    只能基于 validation，不能因 locked-test 结果回调。
[x] C3. 使用 3 个独立训练 seed 完成 F1 正式训练；每个 run 必须保存 checkpoint、
    effective YAML、源码 hash、依赖/GPU 信息和 TensorBoard 日志。
[x] C4. 在 F1 完成前不启动 F2。仅当 F1 在困难域出现可解释且一致的收益时，才训练
    F2 = F1 + belief 年龄/不确定度显式特征；否则以 F1 的正/负结果结束本轮方法开发。
    共同 locked-test 审计后，F1/F2 必须在 P1 的 test seed 642001 上比较。F2 相对 F1
    的 raw Safe Capture 配对差值为：常规 +5.33 +/- 14.97 pp、时延 +3.00 +/- 16.29 pp、
    突发遮挡 +1.67 +/- 7.59 pp、通信丢包 +6.33 +/- 18.81 pp；四个区间均跨 0。
    因此不宣称普遍或显著改善，F2 作为本轮最后一个消融，后续停止继续堆叠方法。

阶段 D：冻结测试、统计与结论

[x] D1. 在四个冻结测试域评估 D、E、F1；如 C4 的启动条件满足，再加入 F2。
    raw action 与 CBF action 必须分别评估。
[x] D2. 每种方法至少 3 个独立训练 seed；每个主要测试域每个 seed 至少 100 回合。
    以训练 seed 为统计重复单位，报告均值、标准差、95% Student-t CI 和配对差值。
[x] D3. 联合报告策略结果与 belief 结果：Observation Age、估计误差、重获观测恢复时间、
    最小间距和 CBF 修正量，解释性能变化的原因。
[x] D4. 只有在至少 2/3 训练 seed 同方向改善，且置信区间与失败轨迹相互支持时，才表述为
    “在指定困难域改善”；否则如实报告失效边界。
[x] D5. 输出正式 Markdown 报告、结构化 JSON、代表性成功/失败三维轨迹和可复现命令。

不是飞控建模，也不需要实飞数据。

[ ] E1. 仅加入动作延迟、速度/加速度上限、控制噪声和一阶速度跟踪误差。
[ ] E2. 设置轻扰动与强扰动两域，先评估冻结的最佳策略；不立即重新训练。
[ ] E3. 单独报告理想运动学与扰动运动学，并记录 desired/executed action 误差。
[ ] E4. 若阶段 D 没有清晰结论，或 E 阶段超过一个实验周期，停止扩展。

阶段 F：sim-to-sim / 实物系统验证（未来子课题）

[ ] F1. 只有阶段 D 结论稳定，才考虑迁移至 PyBullet 或简化四旋翼模型。
