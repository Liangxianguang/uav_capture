0. 一句话目标、研究边界与完成判据
======================================================================

研究目标：
    在固定的三维运动学仿真中，验证 4 架追捕无人机能否在部分可观测、
    中央随机混合静态障碍和持续逃逸目标条件下，通过“学习策略 + CBF
    安全执行层”稳定实现捕获半径内的协同安全捕获。

本阶段的正式结论只覆盖：
    - 4 架追捕机对 1 架逃逸机；r_capture = 0.80 m。
    - 三维运动学环境；障碍物为圆柱、立方体和墙体，位于中央区域。
    - 部分可观测由状态延迟、噪声和丢失等抽象观测扰动实现，不等同于相机检测。
    - CBF 是执行栈的一部分；策略原始动作（raw）必须单独报告，不能把 CBF
      带来的安全性全部归因于网络。

本阶段不主张：
    - 实飞、实体接触/网捕、飞控闭环或真实相机端到端感知；
    - 动态障碍、多目标围捕、未知地图同时加入；
    - 用单个成功视频证明方法有效；
    - 为获得更好画面修改捕获半径、碰撞规则或锁定测试场景。

主指标和最低通过线（仅在预先声明的 V5 validation 上选模型）：
    [ ] Cooperative Safe Capture >= 85%。
    [ ] Collision <= 2%，Boundary violation <= 2%，Transit >= 99%。
    [ ] S1/S2 四种固定布局均 >= 98%，且没有无法解释的安全性回归。
    [ ] 同时报告 Capture、Safe Capture、Cooperative Safe Capture、Timeout、
        Time-to-Capture、最小净空、每架路径长度和 CBF correction。
    [ ] 最终结论在独立 next-locked block 和 3 个独立训练 seed 上复现；若未达标，
        如实保留“V4 Retained BC + CBF 是当前最佳基线”的结论。

术语固定：
    Capture：任一追捕机首次进入目标的 0.80 m 捕获半径。
    Safe Capture：首次 Capture 前无障碍、机间碰撞和越界。
    Cooperative Safe Capture：Safe Capture 且 Capture 前至少 2/4 架追捕机
        进入中央障碍区。目标无需进入或穿过中央区。
    Transit：独立的地图通行性指标，不是 Capture 的附加前提。

4. P2：单因素改进，按证据顺序进行
======================================================================

共同约束：
    - 每轮只改变一个主因素；先 1 个 pilot seed，过 P3 门槛后才扩展。
    - 训练场景、动作尺度、网络结构、序列长度、优化器、capture 定义和 CBF 默认参数
      均保持不变，除非该轮明确研究其中一项。
    - 不在 next-locked block = 647201 上查看或调参。
    - 每个变体保存 YAML、git hash、训练 seed、数据 archive hash 与拒绝样本原因。

P2-A：难例重采样 BC（默认第一优先级）
    触发条件：P1 显示 timeout、窄净空、5 障碍或 delayed_noisy 有稳定失败聚集。
    [ ] A1. 在 P1 已发现的难例条件下，用 rule expert + CBF 生成质量门控演示；
          expert 也无法安全捕获的地图只记录为不可行，不放入训练集。
    [ ] A2. 固定原 V4/V5 常规演示，比较两种唯一变化的数据配比：normal:hard = 1:1
          与 1:2；训练 episode 总数和优化预算保持一致。
    [ ] A3. 记录各条件的采样量、接受率、拒绝原因、左右出生侧及 archive SHA-256；
          保证不是只因某一出生侧或简单布局被过采样。
    [ ] A4. 每个配比先用一个 pilot seed 训练和评估；只保留同时改善 hard group 且
          S1/S2 不退化的一个候选。

P2-B：观测鲁棒性增强（仅在 A 不足且失败主要来自 delayed_noisy 时）
    触发条件：P1/P2-A 显示 delayed_noisy 仍明显弱于 nominal，且主要是预测滞后/超调。
    [ ] B1. 只改变一种训练观测增强，顺序为 delay -> noise -> dropout；每次只打开一项。
    [ ] B2. 对每一项比较 nominal-only、delayed_noisy-only、mixed；总训练量保持一致。
    [ ] B3. 结果必须分条件报告；不能以 nominal 提升掩盖 delayed_noisy 退化。

P2-C：轻量协同辅助项（仅在 P1 证明为协同失效时）
    触发条件：多次失败表现为单机追击、队形塌缩或 2/4 zone entry 持续不满足，
              而非纯粹窄通道/CBF 限制。
    [ ] C1. 先生成诊断图：每架追捕机 zone-entry 顺序、最小距离、最终接近方向、
          agent-agent distance 和 CBF correction 时间序列。
    [ ] C2. 仅增加一个可解释辅助损失（如分散接近或 zone-entry 进度）；做无/有
          辅助项消融，不更改 0.80 m 捕获半径或强迫目标穿越中央区。
    [ ] C3. 若 Capture、最小净空或固定 S1/S2 下降，拒绝该变体。

P2-D：CBF 敏感性诊断（不是学习策略改进）
    [ ] D1. 在冻结同一策略上比较 raw、CBF-default 和少量预先声明的 safety margin。
    [ ] D2. 仅使用 validation 分析 safety margin、Collision、Boundary、Timeout、
          CBF correction、路径长度和 Time-to-Capture 的权衡。
    [ ] D3. 选择最终 CBF 参数后冻结；不得根据 next-locked 结果再次调节。

明确暂缓：
    [ ] MAPPO 仅在 A/B 均未过门槛，且失败被证实为长期协同决策不足时才启动。
          若启动，必须从合格 BC 初始化，并使用行为保持正则；先过 S1/S2 raw/CBF 回归。
    [ ] 不在本阶段同时加入动态障碍、未知地图、真实视觉或复杂六自由度动力学。

        Timeout、Transit。
    [ ] Time-to-Capture、最小净空、每架路径长度、CBF correction 的均值、标准差、
        中位数及分位数；不能只报均值。

    [ ] 没有靠明显加长 episode 时间、恶化最小净空或异常增大 CBF correction 换取成功率。
