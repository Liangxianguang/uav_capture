中央混合障碍区双向三维协同捕获实验计划（V4）
日期：2026-08-20

======================================================================
一、这一次真正要完成的目标
======================================================================

在固定三维边界、部分可观测的环境中，4 架追捕无人机从中央障碍区左侧、
1 架逃逸目标从右侧远距离出生。圆柱、立方体和墙体只布置在场地中央，
双方必须在不碰撞、不越界的条件下绕过或穿过中央障碍区；目标按自身逃逸
策略持续移动，追捕组在中央区内协同接近，并由至少一架追捕机进入固定捕获半径
r_capture = 0.80 m，完成仿真中的安全捕获。

本阶段的研究问题：
    在中央混合障碍、有限观测和持续逃逸同时存在时，协同策略能否稳定地
    完成“跨区接近 - 绕障拦截 - 捕获半径进入”，且始终留在世界边界内？

术语边界：
    本实验的 Capture 是“追捕机进入目标的捕获半径”，不是物理接触、网捕、
    撞击或实飞实体捕获。捕获发生后目标应终止，不能再要求它继续飞到对侧。

======================================================================
二、任务合同：先固定，再训练和展示
======================================================================

1. 空间、出生与障碍物

    [ ] 世界边界固定为 x,y ∈ [-10, 10] m，z ∈ [0.5, 10] m；所有主体
        必须与边界保持至少 1.0 m 的安全缓冲。
    [ ] 中央障碍区固定为 obstacle_zone_x = [-2.5, 3.0] m。障碍物不得出现
        在该区域之外，出生点也不得出现在该区域之内。
    [ ] 4 架追捕机出生于中央区左侧、目标出生于中央区右侧；固定 S2 使用
        x = -5.5 m 和 x = 5.5 m，起点按 y、z 分散，最近初始距离不小于 10 m。
    [ ] 第一版固定混合场景使用 1 个圆柱、1 个立方体和 1 面有明确通道的墙体。
        障碍物组合必须留下可见、可飞行的通道，不能把中央区做成无解迷宫。
    [ ] 任何随机地图都要在“障碍物膨胀半径 = 主体半径 + safety_margin”后
        通过可达性检查；无解地图重新采样并记录拒绝原因。

2. 主捕获回合的成功定义

    [ ] Capture：min_i ||pursuer_i - target|| <= 0.80 m。
    [ ] Safe Capture：首次进入捕获半径之前没有障碍物碰撞、机间碰撞或边界违规。
    [ ] Central Encounter：捕获前至少 2/4 架追捕机已进入中央障碍区。这个条件
        避免“在出生侧立即追上”的伪成功，并能证明结果是协同绕障拦截，而不是
        单机近距离追击。目标在主回合中不要求进入或穿过中央区。
    [ ] Cooperative Safe Capture：Safe Capture + Central Encounter。
    [ ] 记录每架追捕机的 zone-entry 时间、最近距离、路径长度、最小净空和
        终止原因；不要只保存“是否捕获”一个布尔值。

3. “所有主体都能过障碍物”的正确验证方式

    [ ] 主捕获回合只要求发生 Cooperative Safe Capture；目标一旦被捕获即停止。
    [ ] 单独建立 Transit 验证：目标按右到左、每架追捕机按左到右分别执行
        保守可控路径，均需安全到达对侧外部区域。
    [ ] Transit 与主捕获回合分别统计，不把“先捕获后继续穿越”误当作真实任务。
        这样既能证明每个主体均可通过障碍区，也不破坏拦截任务本身。

三、场景设计：中央集中、由简到繁，但始终可解释
======================================================================

S0：几何与规则烟雾测试

    [ ] 校验圆柱、立方体、墙体的碰撞体、渲染外形与 clearance 计算一致。
    [ ] 校验边界、出生点、捕获半径、zone-entry 和 Transit 事件独立且正确记录。
    [ ] 用确定性路径分别证明一条合法路径和一条碰撞/越界路径会被正确判定。

S1：固定单障碍跨区拦截（最小学习任务）

    [ ] 分别使用中央圆柱、中央立方体、带门洞或绕行端点的中央墙体。
    [ ] 双方仍从中央区两侧出生；目标按可复现的正常逃逸路径持续移动，不要求
        主动进入中央区。
    [ ] 每种布局先由 rule expert + CBF 连续完成 20 回合，确认地图和动力学可解。

S2：固定混合障碍展示场景（主要视频场景）

    [ ] 使用圆柱 + 立方体 + 墙体，全部位于中央区，通道宽度由膨胀后几何验证。
    [ ] 追捕机和目标在中央区两侧、不同高度和横向位置出生，初始距离保持较远。
    [ ] 固定 layout seed、motion seed、相机与渲染参数；只选择同时满足
        Cooperative Safe Capture 和独立 Transit Success 的轨迹作正式展示。

S3：随机中央混合障碍泛化场景（正式统计）

    [ ] 随机采样 3-5 个障碍物，类型来自 cylinder、box、wall；位置、尺度、
        高度和通道变化都限制在中央区内。
    [ ] 训练、validation 与 locked-test 使用不重叠的 layout seed 和 target-motion seed。
    [ ] S1/S2 始终保留为回归集，随机化不能掩盖固定场景退化。

S4：只在 S3 稳定后逐项扩展

    [ ] 每次只新增一个因素：更窄但仍可行的通道、障碍物高度变化、墙体门洞位置、
        障碍物簇，或更强的目标转向。
    [ ] 不在本阶段同时引入动态障碍、复杂飞控、真实传感器噪声和新网络结构。
        先得到可复现的三维协同捕获结论，再单独研究这些扩展。

四、训练与不训练的决策规则
======================================================================

    [ ] 改变画面配色、相机、轨迹渲染或固定障碍物外观，不需要重新训练。
    [ ] 仅当现有 checkpoint 在已验证可解的 S1/S2 上无法达到 Cooperative Safe
        Capture，才将其判为任务分布变化并启动重新训练。
    [ ] 新场景先由 rule expert + CBF 通过可解性门槛，再用于训练；若专家都无法
        安全通过，应修正地图、通道或目标机动，而不是堆叠更复杂的模型。
    [ ] 现有 BC checkpoint 先在固定 S1/S2 上单独评估，得到真实初始化基线。
    [ ] 若基线不足，采用 BC -> Recurrent MAPPO + CBF，而不是直接从零训练 MAPPO。

课程顺序：

    [ ] C1：S1 单障碍、确定性目标逃逸路径。
    [ ] C2：S2 固定混合障碍、宽通道、少量横向和高度扰动。
    [ ] C3：S3 随机 3 个混合障碍与有限目标转向。
    [ ] C4：S3 随机 3-5 个障碍、完整部分观测与目标机动范围。
    [ ] 每升一级保留前一级样本，防止遗忘；每个阶段只增加一个主要难度因素。
    [ ] 保存 effective YAML、git hash、checkpoint、training.csv、TensorBoard 日志、
        GPU/依赖信息；validation 选模型，locked-test 只在模型冻结后运行。
